# TransFP Review Experiment Dashboard

Unlisted, noindex static dashboard for review experiment planning and verified result snapshots.

## Update workflow

1. Refresh `data/status.json` from verified server artifacts.
2. Keep raw reviewer text, credentials, IP addresses, usernames, and absolute server paths out of the public snapshot.
3. Validate JSON and JavaScript before deployment.
4. Push to the GitHub Pages repository.

Current public path: `/transfp-review/`.

A dedicated custom subdomain requires a DNS CNAME record and a compatible GitHub Pages custom-domain configuration.
